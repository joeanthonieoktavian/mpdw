Uji ADF

Untuk memeriksa apakah data latih telah stasioner dalam rata-rata, dilakukan uji formal Augmented Dickey-Fuller (ADF) dengan hipotesis sebagai berikut:

  • \(H_0\) : Data memiliki akar unit / unit root (Data tidak stasioner).
  • \(H_1\) : Data tidak memiliki akar unit / unit root (Data stasioner).

Tingkat Signifikansi (\(\alpha\)): 0,05 (5%)

Kriteria Pengambilan Keputusan: * Jika \(p\text{-value} < \alpha\) (\(0,05\)), maka Tolak \(H_0\) (Data stasioner). * Jika \(p\text{-value} \ge \alpha\) (\(0,05\)), maka Gagal Tolak \(H_0\) (Data tidak stasioner).

Box-Cox

# 1. Bikin indeks sesuai jumlah observasi data train (816 data)
index <- seq(1:length(train.ts))

# 2. Plot Box-Cox
bc <- boxcox(train.ts ~ index, lambda = seq(0.5, 2, by = 0.1))

lambda_opt

# 4. Selang kepercayaan 95% untuk lambda
ci_lambda <- bc$x[bc$y > max(bc$y) - 0.5 * qchisq(0.95, df = 1)]

ci_lower <- min(ci_lambda)

## Batas_Bawah  Batas_Atas 
##    1.454545    1.590909

Pemeriksaan stasioneritas dalam ragam (varians) dilakukan menggunakan pengujian Box-Cox pada data latih (train set). Hasil analisis diperlihatkan pada plot Box-Cox serta parameter yang diperoleh sebagai berikut:

  • Nilai Lambda Optimum (\(\hat{\lambda}\)) : \(1,515\)
  • Selang Kepercayaan 95% : \([1,454 \ ;\ 1,591]\)

Interpretasi Plot & Hasil Pengujian:

Plot memperlihatkan kurva log-likelihood berbentuk parabola cekung ke atas. Puncak tertinggi dari kurva tersebut berada tepat pada nilai \(\lambda = 1,515\), yang menunjukkan nilai transformasi paling optimal untuk menstabilkan keragaman data.

Berdasarkan batas selang kepercayaan \(95\%\) (daerah di atas garis horizontal putus-putus pada plot), diperoleh rentang nilai \(\lambda\) antara \(1,454\) hingga \(1,591\).

Karena selang kepercayaan \(95\%\) tersebut tidak memuat nilai \(1\) (\(\lambda = 1 \notin [1,454 \ ;\ 1,591]\)), maka dapat disimpulkan bahwa data latih belum stasioner dalam ragam.

# 2. Shifting data agar tidak negatif
min_val <- min(train.diff)

Pengujian Box-Cox secara formal dilakukan kembali pada data hasil diferensiasi pertama (train.diff) yang telah digeser (shifting) dengan konstanta \(c \approx 401\) agar seluruh observasi bernilai positif. Hasil pengujian menghasilkan nilai \(\lambda_{\text{optimum}} \approx 2.65\) dengan selang kepercayaan \(95\%\) sebesar \([2.65 \ ;\ 3.00]\).

Penyebab & Evaluasi Metodologis:

  1. Efek Skala Penggeseran (Shifting Artifact): Nilai \(\lambda > 1\) yang tinggi ini muncul sebagai akibat dari penambahan konstanta penggeser yang sangat besar (\(c \approx 401\)) untuk mengakomodasi pencilan ekstrem era COVID-19 (tahun 2020). Penambahan skala konstanta ini mengubah struktur sebaran data asli sehingga fungsi log-likelihood Box-Cox merekomendasikan pangkat yang lebih tinggi secara matematis.
  2. Pemeriksaan Visual: Secara visual pada plot deret waktu diferensiasi pertama, di luar pencilan tunggal era COVID-19, fluktuasi data sudah bergerak secara konsisten pada rentang pita yang relatif konstan di sekitar rata-rata nol.

Kesimpulan:

Berdasarkan pertimbangan visual dan karakteristik outlier akibat krisis global COVID-19, data hasil diferensiasi pertama (\(d=1\)) disimpulkan telah memenuhi asumsi kestasioneran ragam secara praktis dan tidak memerlukan transformasi Box-Cox lanjutan.

Identifikasi Model

Plot ACF

acf(train.diff)

Plot PACF

pacf(train.diff)

Berdasarkan hasil visualisasi plot Autocorrelation Function (ACF) dan Partial Autocorrelation Function (PACF) pada data latih pasca-diferensiasi pertama (\(d=1\)), diperoleh identifikasi pola sebagai berikut:

  • Plot PACF: Menunjukkan adanya lonjakan (spike) yang signifikan pada Lag 1 dan mengalami cuts off pada lag-lag awal berikutnya. Pola ini mengindikasikan keberadaan komponen Autoregressive orde satu atau AR(1) (\(p=1\)).
  • Plot ACF: Menunjukkan spike signifikan pada Lag 1 yang kemudian langsung terputus (cuts off), mengindikasikan keberadaan komponen Moving Average orde satu atau MA(1) (\(q=1\)).

Berdasarkan pola grafik fungsi autokorelasi tersebut, disusulkan 3 kandidat model ARIMA non-musiman untuk diestimasi:

  1. ARIMA(1,1,0)
  2. ARIMA(0,1,1)
  3. ARIMA(1,1,1)

Catatan Analisis: Adanya gejolak struktural (shock) ekstrem pada era pandemi COVID-19 (2020–2021) memberikan variansi sisaan yang cukup besar pada deret waktu. Meski demikian, ketiga kandidat model ARIMA di atas tetap digunakan sebagai model statistik dasar (baseline) sesuai dengan cakupan metodologi Box-Jenkins klasik.

Hasil EACF ini memperkuat temuan dari plot ACF dan PACF sebelumnya yang mengarah pada kandidat utama ARIMA(0,1,1) dan ARIMA(1,1,1).

Pendugaan Parameter Model Tentatif

Berdasarkan sintesis menyeluruh dari plot ACF, PACF, dan matriks EACF pada data latih hasil differencing pertama (\(d=1\)), diperoleh daftar kandidat model ARIMA non-musiman yang akan diestimasi dan dibandingkan parameternya:

  1. ARIMA(0,1,1) — Kandidat Utama (Berdasarkan ACF cut off Lag 1 & EACF AR=0, MA=1)
  2. ARIMA(1,1,1) — Kandidat Campuran Utama (Berdasarkan ACF, PACF, & EACF AR=1, MA=1)
  3. ARIMA(1,1,0) — Kandidat Autoregressive (Berdasarkan PACF cut off Lag 1)
  4. ARIMA(0,1,2) — Kandidat Alternatif MA (Berdasarkan pola segitiga nol EACF)
  5. ARIMA(1,1,2) — Kandidat Tambahan (Berdasarkan segitiga nol EACF AR=1, MA=2)
  6. ARIMA(2,1,1) — Kandidat Tambahan (Berdasarkan segitiga nol EACF AR=2, MA=1)

Hasil peramalan menunjukkan nilai yang cenderung konstan (flat/linear trend) mulai dari periode ketiga (\(h \ge 3\)). Hal ini secara teoritis merupakan sifat alamiah (property) dari model ARIMA(0,1,2) pada data terintegrasi derajat satu (\(d=1\)).

Karena model tidak memuat komponen Autoregressive (\(p=0\)) dan tidak memiliki variabel drift (konstanta), maka memori komponen Moving Average (\(q=2\)) hanya memberikan penyesuaian pada 2 periode pertama. Selanjutnya, nilai ramalan diferensiasi bergerak menuju nilai ekspektasi nol, sehingga nilai hasil inverse differencing menghasilkan garis proyeksi yang stabil/konstan. Meskipun bersifat konstan, hasil peramalan ini tetap memiliki tingkat akurasi yang tinggi karena berada sangat dekat dengan garis data aktual.

Untuk menguji kebaikan dan presisi peramalan model ARIMA(0,1,2) pada data testing (test.ts), dilakukan perhitungan beberapa kriteria ukuran kebaikan (error measures):

  • Mean Absolute Percentage Error (MAPE): Sebesar \(2{,}89\%\). Berdasarkan kriteria evaluasi akurasi, nilai MAPE \(< 10\%\) mengindikasikan bahwa kemampuan peramalan model berada pada kategori sangat akurat.
  • Root Mean Squared Error (RMSE): Sebesar \(256{,}75\).
  • Mean Absolute Error (MAE): Sebesar \(235{,}98\).
  • Mean Percentage Error (MPE): Sebesar \(2{,}89\%\).
